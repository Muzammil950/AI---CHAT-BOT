## ✨ About The Project

**AI Chatbot** is a beginner-friendly Python project that simulates a conversation between a user and a chatbot.

The chatbot understands basic user messages such as greetings, asking about its name, checking the current time, and exiting the conversation.

This project is created to learn the fundamentals of:

- 🐍 Python
- 🔀 Conditional Statements
- 🔁 Loops
- 🧩 Functions
- 📦 Modules
- ⌨️ User Input
- 🤖 Basic Chatbot Logic

---

## 🎯 Features

| Feature | Description |
|---|---|
| 👋 Greetings | Responds to `hello` and `hii` |
| 😊 Conversation | Responds to `how are you` |
| 🤖 Bot Identity | Tells the chatbot's name |
| 🕐 Current Time | Displays the current system time |
| 🚪 Exit | Supports `bye` and `exit` |
| 💬 Interactive Chat | Continuous conversation through the terminal |

## 🧠 How It Works

The chatbot follows a simple rule-based approach:

```text
        👤 User Input
              │
              ▼
      Convert to lowercase
              │
              ▼
       Check user message
              │
       ┌──────┼──────┐
       ▼      ▼      ▼
    Greeting  Time   Exit
       │      │      │
       ▼      ▼      ▼
    Response Response Goodbye
```

The chatbot checks the user's input using Python `if`, `elif`, and `else` statements.
